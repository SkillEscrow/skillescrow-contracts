# SkillEscrow Bounties — skillescrow-contracts

> Paid GitHub issues with AI PR triage, settled in USDC on Stellar/Soroban.

Soroban escrow contract for SkillEscrow Bounties: lock USDC on a GitHub issue, pay the contributor when their PR is merged.

Maintainers lock USDC on a GitHub issue. Contributors submit PRs. An AI ranks and reviews every PR against the issue. **Merging the PR pays the contributor automatically.**

**Status:** under active development (Phase 0 — setup).

## History
